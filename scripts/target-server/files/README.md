# 纳管服务器文件网关

文件能力使用同一个非 root `aioms` SSH 身份，但只能经 root 持有的三个固定包装器执行：

- `aioms-file-read`：在已授权目录查找文件、脱敏读取文本，并在目标机生成结构化补丁预览；
- `aioms-file-policy`：由 AIOMS 服务目录页面同步可读目录或精确可写文件；
- `aioms-file-write`：校验预览时的 SHA-256、保留权限、生成备份并原子替换；
- `config_patch.py`：只在目标机处理 dotenv 已有变量或 JSON Pointer 指向的 JSON/YAML 已有标量，其他真实字段不会返回后端。

默认白名单为空。私钥、`/etc/shadow`、sudoers 等路径始终禁止；包含密码、Token、连接串凭据的行只返回脱敏值。

结构化补丁只允许精确写授权文件，并拒绝敏感字段、自动新增、对象/数组替换、重复键和含换行值。dotenv、JSON 与 YAML 补丁只替换目标标量的原始字节；YAML 还会拒绝别名、合并键和自定义标签，避免一个路径影响多个字段。普通文本仍走完整 diff 的整文件更新。

文件网关不会执行配置校验、reload、服务重启或部署。需要让新配置生效时，由 Agent 在文件修改成功后调用独立的调查或服务变更能力，并按操作自身的风险级别进入审批。
